# LegalEase – AI-Powered Legal Document Generator

LegalEase is an AI-powered application that helps users generate legal document drafts using Google Gemini AI.

## Features
- AI-powered legal document generation
- Multiple document types
- PDF, DOCX, and TXT downloads
- Editable generated content

## Technologies
- Python
- FastAPI
- Streamlit
- Google Gemini API

## Disclaimer
AI-generated documents are drafts and should be reviewed by a qualified legal professional before signing.
